# plocks Pinterest-style ideas

A searchable idea grid with detail views and saved pins. Art and ideas are local placeholders.

This standalone Expo example uses `@plocks/ui` components through the shared [`ExampleUI.tsx`](../example-common/ExampleUI.tsx) layout and a light or dark `PlocksProvider` theme. Its main interaction lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/pinterest-app
```

Use `npm run start -w @plocks/pinterest-app` for Expo, or `npm run typecheck -w @plocks/pinterest-app` to check TypeScript.
