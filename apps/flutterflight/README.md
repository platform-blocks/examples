# plocks Flutterflight

A tap-to-flap arcade game with moving pipes, collisions, scoring, and restart.

This standalone Expo example uses `@plocks/ui` components in a full-screen playfield. The score and restart control sit over the game, which adapts to the available screen size. Its main interaction lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/flutterflight
```

Use `npm run start -w @plocks/flutterflight` for Expo, or `npm run typecheck -w @plocks/flutterflight` to check TypeScript.
