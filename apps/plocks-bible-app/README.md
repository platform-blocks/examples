# plocks Bible reader

A passage reader with three King James Version excerpts and a session bookmark list.

This standalone Expo example uses `@plocks/ui` components through the shared [`ExampleUI.tsx`](../example-common/ExampleUI.tsx) layout and a light or dark `PlocksProvider` theme. Its main interaction lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/bible-app
```

Use `npm run start -w @plocks/bible-app` for Expo, or `npm run typecheck -w @plocks/bible-app` to check TypeScript.
