# plocks Calculator

A four-function calculator with decimals, percent, sign change, and chained operations.

This standalone Expo example uses `@plocks/ui` components through the shared [`ExampleUI.tsx`](../example-common/ExampleUI.tsx) layout and a light or dark `PlocksProvider` theme. Its main interaction lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/calculator-app
```

Use `npm run start -w @plocks/calculator-app` for Expo, or `npm run typecheck -w @plocks/calculator-app` to check TypeScript.
