# Frameleaf

A photo sharing example built with plocks and Expo. Browse a feed and stories, search Explore, view a profile, and create a demo post. Multi-image posts use the Plocks Carousel; tapping a photo opens the Plocks Lightbox at that image. Likes, saves, comments, and posts are saved locally with AsyncStorage. The gallery uses bundled demo artwork; no account or backend is required.

Run from the plocks root:

```bash
npm install
npm run web -w @plocks/frameleaf
```
