# plocks Flight tracker

A searchable fictional flight list with route details, gate, times, and static route progress. No live tracking.

This standalone Expo example uses `@plocks/ui` components with a light or dark `PlocksProvider` theme. Its main interaction lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/flight-tracker
```

Use `npm run start -w @plocks/flight-tracker` for Expo, or `npm run typecheck -w @plocks/flight-tracker` to check TypeScript.
