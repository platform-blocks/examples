# Finster

A playful fish matching example built with plocks and Expo. Swipe fish cards or use the pass, super like, and like controls. Mutual likes appear in Matches, where you can start a local chat. Choices and messages are saved with AsyncStorage; no account or backend is required.

Run from the plocks root:

```bash
npm install
npm run web -w @plocks/fish-dating-app
```
