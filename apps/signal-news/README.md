# plocks Signal News

An audio-news-inspired reading screen with search, saved stories, and a sample playback timer. Headlines and summaries are original sample content; no live feed or audio.

This standalone Expo example uses `@plocks/ui` components with a light or dark `PlocksProvider` theme. Its main interaction lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/signal-news
```

Use `npm run start -w @plocks/signal-news` for Expo, or `npm run typecheck -w @plocks/signal-news` to check TypeScript.
