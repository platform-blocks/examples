# Townlist

A Craigslist-inspired classifieds example built with plocks and Expo. Search and filter listings, save favorites, publish a local listing, and compose demo inquiries. Listings, saved items, and inquiries are saved with AsyncStorage. Messages stay on the device; no account or backend is required.

Run from the plocks root:

```bash
npm install
npm run web -w @plocks/craigslist-app
```
