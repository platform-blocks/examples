# plocks Springstep

A full-screen bouncing platform game with press-and-drag steering, procedural platforms, scoring, and restart.

This standalone Expo example uses `@plocks/ui` components and a `PlocksProvider` theme. Press or drag across the playfield to move the character horizontally. Its main interaction lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/springstep
```

Use `npm run start -w @plocks/springstep` for Expo, or `npm run typecheck -w @plocks/springstep` to check TypeScript.
