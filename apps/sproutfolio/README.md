# Sproutfolio

An investing dashboard built with plocks and Expo. Browse a demo portfolio and chart, search stocks, manage a watchlist, and place simulated buy or sell orders. Holdings, cash, watchlist, and activity are saved with AsyncStorage. Prices are fictional; no account, brokerage connection, or real trade is involved.

Run from the plocks root:

```bash
npm install
npm run web -w @plocks/sproutfolio
```
