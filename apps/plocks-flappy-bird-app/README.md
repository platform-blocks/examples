# plocks Flappy Bird

A tap-to-flap arcade game with moving pipes, collisions, scoring, and restart.

This standalone Expo example uses `@plocks/ui` components through the shared [`ExampleUI.tsx`](../example-common/ExampleUI.tsx) layout and a light or dark `PlocksProvider` theme. Its main interaction lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/flappy-bird-app
```

Use `npm run start -w @plocks/flappy-bird-app` for Expo, or `npm run typecheck -w @plocks/flappy-bird-app` to check TypeScript.
