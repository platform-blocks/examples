# plocks Daymark activity

A wellness dashboard with daily steps, sleep stages and history, heart rate, weight trends, hydration, and local logging. No wearable connection.

This standalone Expo example uses `@plocks/ui` components and a `PlocksProvider` theme. Its dashboard and local logging live in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/daymark
```

Use `npm run start -w @plocks/daymark` for Expo, or `npm run typecheck -w @plocks/daymark` to check TypeScript.
