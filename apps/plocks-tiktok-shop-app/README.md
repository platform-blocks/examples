# Loopshop

A TikTok Shop-inspired storefront built with plocks and Expo. Swipe through static demo product creatives, like and comment, browse the shop, and manage a cart. Product details can be shared. Cart, likes, and comments are saved with AsyncStorage. Checkout is a demo and does not process payment.

Run from the plocks root:

```bash
npm install
npm run web -w @plocks/tiktok-shop-app
```
