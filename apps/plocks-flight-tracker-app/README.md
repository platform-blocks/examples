# plocks Flight tracker

A searchable fictional flight list with route details, gate, times, and static route progress. No live tracking.

This standalone Expo example uses `@plocks/ui` components through the shared [`ExampleUI.tsx`](../example-common/ExampleUI.tsx) layout and a light or dark `PlocksProvider` theme. Its main interaction lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/flight-tracker-app
```

Use `npm run start -w @plocks/flight-tracker-app` for Expo, or `npm run typecheck -w @plocks/flight-tracker-app` to check TypeScript.
