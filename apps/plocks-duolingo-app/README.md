# plocks Duolingo-style language lesson

A four-question beginner Spanish lesson with answer feedback, progress, and score.

This standalone Expo example uses `@plocks/ui` components through the shared [`ExampleUI.tsx`](../example-common/ExampleUI.tsx) layout and a light or dark `PlocksProvider` theme. Its main interaction lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/duolingo-app
```

Use `npm run start -w @plocks/duolingo-app` for Expo, or `npm run typecheck -w @plocks/duolingo-app` to check TypeScript.
