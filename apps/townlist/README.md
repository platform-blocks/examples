# Townlist

A classifieds example built with plocks and Expo. Search and filter listings, save favorites, publish a local listing, and compose demo inquiries. Photo listings open a Plocks Lightbox with full-screen navigation. Listings, saved items, and inquiries are saved with AsyncStorage. Messages stay on the device; no account or backend is required.

Demo photos are bundled locally. The bicycle photo is from [Unsplash](https://unsplash.com/photos/tG36rvCeqng); the other photos and credits are shared with the [Idea Grid demo](../idea-grid/README.md).

Run from the plocks root:

```bash
npm install
npm run web -w @plocks/townlist
```
