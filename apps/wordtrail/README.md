# plocks Wordtrail language lesson

A four-question beginner Spanish lesson with animated progress, illustrated prompts, answer feedback, hearts, and a completion screen.

This standalone Expo example uses `@plocks/ui` components and a `PlocksProvider` theme. Its lesson flow lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/wordtrail
```

Use `npm run start -w @plocks/wordtrail` for Expo, or `npm run typecheck -w @plocks/wordtrail` to check TypeScript.
