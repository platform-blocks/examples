# plocks Calculator

A four-function calculator with decimals, percent, sign change, and chained operations.

This standalone Expo example uses only `@plocks/ui` components for its full-screen display and keypad. Each key occupies an equal grid slot, and the `0` key spans two slots. Its layout and interaction live in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/calculator
```

Use `npm run start -w @plocks/calculator` for Expo, or `npm run typecheck -w @plocks/calculator` to check TypeScript.
