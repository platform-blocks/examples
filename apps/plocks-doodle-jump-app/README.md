# plocks Doodle Jump

A bouncing platform game with left/right steering, procedural platforms, scoring, and restart.

This standalone Expo example uses `@plocks/ui` components through the shared [`ExampleUI.tsx`](../example-common/ExampleUI.tsx) layout and a light or dark `PlocksProvider` theme. Its main interaction lives in [`App.tsx`](./App.tsx).

## Run

From the `plocks` repository root:

```bash
npm install
npm run web -w @plocks/doodle-jump-app
```

Use `npm run start -w @plocks/doodle-jump-app` for Expo, or `npm run typecheck -w @plocks/doodle-jump-app` to check TypeScript.
