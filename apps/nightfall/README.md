# Nightfall

A streaming app built with plocks and Expo. Pick a profile on the "Who's watching?" screen, then browse a home feed with TV Shows / Movies / Categories filters, Continue Watching progress, a Top 10 shelf with big rank numbers and genre rows. Every title opens its own page with match, rating and HD badges, Play and simulated Download, cast, genres and moods, My List / Rate / Share, an Episodes tab with a season picker, More Like This and Trailers & More; Back returns to where you were. Search shows Top Searches before you type and an even poster grid after. New & Hot has Coming Soon with Remind Me, Everyone's Watching and Top 10 lists, and My Nightfall gathers notifications, downloads, liked titles, My List and trailers you've watched. The plocks Video player plays a bundled sample clip for every title; the catalog, people and episodes are fictional demo content. List, ratings, reminders, downloads and playback progress are saved locally.

Run from the `examples` root, alongside the `plocks` checkout:

```bash
npm install
npm run web -w @plocks/nightfall
```
