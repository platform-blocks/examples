# Nightfall

A streaming catalog built with plocks and Expo. Browse titles, search, save a My List, and open details with a cast marquee. The plocks Video player plays a bundled sample clip; the catalog titles and actors are fictional demo content. List and playback progress are saved locally.

Run from the `examples` root, alongside the `plocks` checkout:

```bash
npm install
npm run web -w @plocks/nightfall
```
