# Loopshop

A social storefront built with plocks and Expo. The feed uses the vertical `@plocks/carousel` with full-height, snapping slides so you can swipe through static demo product creatives. Like and comment, browse the shop, and manage a cart. Product details can be shared. Cart, likes, and comments are saved with AsyncStorage. Checkout is a demo and does not process payment.

Run from the plocks root:

```bash
npm install
npm run web -w @plocks/loopshop
```
